# Sistema de Aprovação

Projeto desenvolvido em Python durante meus estudos de Análise e Desenvolvimento de Sistemas.

## Sobre o projeto

O programa recebe o nome do aluno, sua nota e sua frequência e verifica sua situação acadêmica.

O aluno pode ser classificado como:

* Aprovado
* Recuperação
* Reprovado

## Conceitos praticados

* Variáveis
* `input()`
* Conversão de tipos
* `if`, `elif` e `else`
* Operadores de comparação
* Operadores lógicos (`and`)

## Como executar

1. Tenha o Python instalado.
2. Abra o arquivo `sistema_aprovacao.py`.
3. Execute o programa pelo terminal ou pelo VS Code.
4. Informe o nome, a nota e a frequência do aluno.

## Objetivo

Praticar os fundamentos de Python e estruturas de decisão por meio de um pequeno projeto.
